Première version publique de **RpgMasters Helper**, l'extension de navigateur non officielle qui conseille les joueurs de [RpgMasters](https://rpgmasters.houk.fr/).

## Installation
1. Télécharge `rpgmasters-helper-v0.11.1.zip` ci-dessous et décompresse-le.
2. Ouvre `chrome://extensions` (ou `edge://extensions`), active le **mode développeur**.
3. Clique sur **Charger l'extension non empaquetée** et choisis le dossier décompressé.
4. Ouvre le jeu : le panneau « Conseiller » apparaît à droite.

## Contenu
- **Profil** : nom, classe, niveau, prestige, progression vers le niveau 200, kamas, énergie (avec alerte discrète quand elle est pleine).
- **À faire maintenant** : étapes concrètes, cochées automatiquement quand elles sont faites.
- **Points de caractéristique** : tout dans une seule stat (Sagesse par défaut, méta XP), bouton « Remplir pour moi », conseil de réinitialisation gratuite.
- **Équipement** : meilleurs objets de l'inventaire (fusion et panoplies compris), bouton « Tout équiper » qui prépare un code d'équipement officiel.
- **Panoplies** et **ménage de l'inventaire** (fusions, objets inutiles).
- **Decks** : 8 cartes par défaut, rotation vol de vie / dégâts / bouclier, **multi-éléments**, synergie avec le passif de classe, code `DM-S-…` prêt à importer.
- **Bestiaire** : monstres de ton niveau, zones et butin, recherche d'objets.

Toutes les données sont lues dans le jeu, avec la session du joueur ; l'extension n'écrit rien et ne fait aucune action à sa place.
